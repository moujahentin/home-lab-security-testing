## Approach and lessons

- Use **explicitly authorized training targets** only.
- Separate an exploit's successful execution from privilege escalation, full-room completion, and formal proof of completion.
- Record observed evidence (commands, system output, task results) while removing lab access tokens and per-session target addresses.
- Be clear about incomplete activities: meaningful learning can happen without a completion badge.
